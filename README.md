# Wedding Invitation – Reham & Abdelrahman

React + Vite.

    npm install
    npm run dev      # local preview
    npm run build    # output in dist/ (upload to any static host)

Edit names, date, venue, map link and WhatsApp number in `src/config.js`.
Replace images in `src/assets/` (frame.webp, divider.webp).

Guestbook: outside Claude it stores wishes in the visitor's browser only.
For a shared guestbook connect a backend (Firebase, Supabase, Google Forms).

`standalone/index.html` is the single-file version (works by double-click, needs internet for React/fonts).
